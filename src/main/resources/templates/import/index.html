Tips
  • Rows with the same client/supplier name and invoice date are grouped into one invoice with multiple line items.
  • Client and supplier names must match exactly (case-insensitive) with existing records.
  • Date format must be yyyy-MM-dd (e.g., 2026-01-15).
  • If a product name is specified in purchase imports, stock will be automatically increased.
  • GST type (CGST+SGST or IGST) is auto-determined based on your state and the client/supplier state.
